# MegaBlog

## 🚀 Overview

Welcome to **MegaBlog**, a modern, integrated blogging platform designed to empower content creators. In today's dynamic digital landscape, creators often struggle with the technical complexities of managing and scaling their platforms. MegaBlog addresses these challenges by combining cutting-edge technologies to offer a highly customizable, scalable, and secure environment. It provides a seamless and intuitive experience, allowing you to focus on crafting compelling content without getting bogged down by infrastructure or technical details.

## ✨ Features

MegaBlog is built to deliver a rich and responsive user experience with a robust set of features:

*   **Secure User Authentication:** Built with Appwrite for secure and efficient user registration, login, and session management.
*   **Rich Content Editing:** Integrate TinyMCE for a powerful and user-friendly rich text editing experience, supporting various formatting options and media embedding.
*   **Dynamic Post Management:** Create, read, update, and delete blog posts with ease.
*   **State Management with Redux Toolkit:** Efficient and predictable state management for a smooth application flow.
*   **Modern UI with React & Tailwind CSS:** A responsive and aesthetically pleasing user interface built with React and styled using Tailwind CSS for rapid and consistent design.
*   **Fast Development with Vite:** Leverage Vite for a lightning-fast development experience and optimized build processes.
*   **Client-side Routing:** Seamless navigation within the application using React Router DOM.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

*   Node.js (LTS version recommended)
*   npm (comes with Node.js)
*   An Appwrite instance (self-hosted or Appwrite Cloud)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/MegaBlog.git
    cd MegaBlog
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Configure Appwrite Environment Variables:**
    Create a `.env` file in the root of the project and add your Appwrite credentials. Replace the placeholder values with your actual Appwrite project details:

    ```
    VITE_APPWRITE_URL=YOUR_APPWRITE_ENDPOINT
    VITE_APPWRITE_PROJECT_ID=YOUR_APPWRITE_PROJECT_ID
    VITE_APPWRITE_DATABASE_ID=YOUR_APPWRITE_DATABASE_ID
    VITE_APPWRITE_COLLECTION_ID=YOUR_APPWRITE_COLLECTION_ID
    VITE_APPWRITE_BUCKET_ID=YOUR_APPWRITE_BUCKET_ID
    ```
    *Refer to your Appwrite console for these values.*

### Running the Project

To start the development server:

```bash
npm run dev
```

This will launch the application in development mode, typically accessible at `http://localhost:5173`. The page will reload if you make edits.

## 📊 Appwrite API Endpoints

This section outlines the key Appwrite API endpoints used by MegaBlog.
*(**Note to Agent/Developer:** Please fill in the specific API endpoints and their functionalities here. You may need to consult the Appwrite backend integration code for exact details.)*

*   **Authentication:**
    *   `POST /account` - Register new user
    *   `POST /account/sessions/email` - Login user with email and password
    *   `GET /account` - Get current authenticated user's details
    *   `DELETE /account/sessions/current` - Logout current user
*   **Database (Posts):**
    *   `POST /databases/[DATABASE_ID]/collections/[COLLECTION_ID]/documents` - Create a new blog post
    *   `GET /databases/[DATABASE_ID]/collections/[COLLECTION_ID]/documents/[DOCUMENT_ID]` - Get a single blog post
    *   `GET /databases/[DATABASE_ID]/collections/[COLLECTION_ID]/documents` - List all blog posts (with optional queries)
    *   `PUT /databases/[DATABASE_ID]/collections/[COLLECTION_ID]/documents/[DOCUMENT_ID]` - Update an existing blog post
    *   `DELETE /databases/[DATABASE_ID]/collections/[COLLECTION_ID]/documents/[DOCUMENT_ID]` - Delete a blog post
*   **Storage (Files/Images):**
    *   `POST /storage/[BUCKET_ID]/files` - Upload a file (e.g., image for a blog post)
    *   `GET /storage/[BUCKET_ID]/files/[FILE_ID]/preview` - Get a file preview (e.g., image thumbnail)
    *   `DELETE /storage/[BUCKET_ID]/files/[FILE_ID]` - Delete a file
